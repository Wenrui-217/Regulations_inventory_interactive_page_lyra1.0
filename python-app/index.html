      接入 SharePoint 资料

      平台不直接登录 SharePoint。把监控文件夹和「相关文件」导出成 JSON。全公司一起看，请把文件保存为 data/catalog.json 再发布；在这里上传只留在你这台浏览器。

      1. Power Automate 读取两个文档库的文件名、链接和正文摘录。
      2. 监控文件夹的 library 写成「监控库」，相关文件夹写成「相关文件」。
      3. originalUrl 放监管机构原网页，fileUrl 放 SharePoint 文件链接。
      4. 生成 JSON 后上传，或把 JSON 放到一个无需登录的 https 地址再同步。

      字段含义
      title法规名称，卡片标题
      summary进一步信息，显示在标题下方
      detail点开后的进一步信息
      originalUrl监管机构原网页
      fileUrlSharePoint 或附件原文件
      library监控库，或相关文件
      source如 PICS、上海药监-药品法规、CFDI
      keywords关键词数组，或用顿号分隔的字符串
      publishedAt发布日期，YYYY-MM-DD
