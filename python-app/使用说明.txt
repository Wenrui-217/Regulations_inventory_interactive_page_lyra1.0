法规信息检索 — 只用 Python 和 VS Code

1. 用 VS Code 打开本文件夹（文件 → 打开文件夹）。
2. 菜单「终端 → 新建终端」，输入下面其中一条后回车：

   python serve.py
   py serve.py

3. 浏览器打开终端里打印的地址，一般是 http://127.0.0.1:8080/
4. 不要直接双击 index.html，那样检索库加载不出来。

改「相关网址」：用 VS Code 打开 data/links.json。每一条有 name（网站名称）、url（网页地址）、note（一句说明）。保存后刷新浏览器。要加一个网站，照着复制一整条，注意逗号。
发布到 EDP 时，上传整个文件夹，不要只上传某一个文件。
